
Лендінг для компанії з ремонту побутової техніки в США.

## Функціонал
- Шапка з навігацією
- Секція послуг (6 послуг)
- Форма запису з валідацією (ім'я, телефон, опис проблеми)
- Адаптивний дизайн
- Сучасний пользовательский интерфейс

## Технології
- HTML
- CSS
- JavaScript

## Примітки
Проєкт створений з використанням AI-інструментів для прискорення розробки та доопрацьований вручну.
